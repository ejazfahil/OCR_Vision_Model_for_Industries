# Contributing

Thank you for your interest in contributing!

## Setup

```bash
git clone https://github.com/ejazfahil/OCR_Vision_Model_for_Industries.git
cd OCR_Vision_Model_for_Industries
pip install -r requirements.txt
pytest tests/  # verify all tests pass
```

## Guidelines
- Write tests for all new features
- Follow PEP8 style
- Update CHANGELOG.md for significant changes
- All PRs go against `main` branch

## Running Tests

```bash
make test           # run all tests
make coverage       # with HTML coverage report
```
